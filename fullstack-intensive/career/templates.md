# Career Package Starters (expand in Weeks 3–6)

## Job post evaluation checklist

1. Required vs nice-to-have tech  
2. New build / enhancement / bugfix / integration  
3. Auth, payments, or AI required?  
4. Deliverables and timeline realistic?  
5. Classify: **Independent** / **With guidance** / **Not yet**  
6. What proof from my portfolio matches?

## Proposal skeleton

1. Restate their problem in one sentence  
2. Approach in 3–5 steps  
3. Questions that unblock scope  
4. Milestone + timeline  
5. Relevant proof (repo/demo)  
6. What is *out* of scope  

## Case study skeleton

Problem → user → scope → stack why → architecture → schema → key decisions → tests → security → limits → what I built → link

## Interview drill themes

JS quirks, async, React state, HTTP/REST, Express middleware, SQL joins, authz vs authn, debugging story from your project.
