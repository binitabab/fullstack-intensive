# Deliverable B (overview) — Strategic Blueprint

**Program start:** Day 1 begins immediately after this blueprint  
**Hours:** 30–40 focused hrs/week (sustainable option: 25 hrs — cut Optional only)  
**Outcome levels (honest):**

| Level | Meaning |
|-------|---------|
| **Beginner competence** | Can follow tutorials and reproduce patterns with help |
| **Independent project competence** | Can build/debug a scoped app with tests and deploy docs |
| **Professional production experience** | Not achievable in 6 weeks alone — years of shipped systems |

Finishing the curriculum ≠ job-ready. Assessment is evidence-based.

---

## Learning strategy

1. **Diagnose first** — skip what you prove; remediate what you can’t.  
2. **One product domain** — **BizFlow** (small-business operations: customers, products/services, orders).  
3. **Skills compound** — JS → React UI → Express API → Mongo → Postgres rebuild of core relations → TS → Next intro → deploy.  
4. **Engineering workflow** on every project: Scope → Audit → Architect → Develop → Test → Check → Document → Sync.  
5. **Career practice weekly** — read one job post, extract requirements, classify suitability.

---

## Six-week overview

| Week | Theme | Core deliverable | Quality gate |
|------|-------|------------------|--------------|
| 1 | JS diagnostic + React start | Expense Tracker + Dashboard shell | Explain/write JS for exercises; interactive UI |

| 3 | Mongo + MERN | BizFlow MERN v1 (auth + CRUD) | Complete user journey with access control |
| 4 | SQL + PERN | Relational schema + PERN feature slice | Useful SQL + working Postgres feature |
| 5 | TS + Next intro + test + deploy | Typed modules + deployed app | Tests + deploy (or verified deploy process) |
| 6 | Capstone + portfolio + career | Polished demo + case studies | Explain/demo app; honest next steps |

## Assessment system

**Mastery scale**

- **0** Not understood  
- **1** Understands explanation  
- **2** Implements with guidance  
- **3** Implements independently  
- **4** Debugs, tests, explains trade-offs, adapts  

**Trackers:** `04-progress-tracker.md` + `continuity-record.md`  
**Weekly gates:** end of each week (practical task, limited hints)  
**Final:** Week 6 candid report across 12 competency areas
