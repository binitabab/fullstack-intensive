# Assessment Rubric (summary)

Full weekly challenges issued at end of each week. Final Week 6 covers 12 areas from the Master Prompt.

| Level | Label | Evidence required |
|-------|-------|-------------------|
| 0 | Not understood | Cannot explain or implement |
| 1 | Understands | Accurate explanation, no working code yet |
| 2 | Guided | Works with hints/review |
| 3 | Independent | Implements from spec without solution dump |
| 4 | Adaptive | Debugs novel failures, tests, explains trade-offs |

**Week gates:** see `02-42-day-schedule.md`.  
**Rule:** Reading ≠ mastery. Passing a gate requires a working artifact + explanation.
