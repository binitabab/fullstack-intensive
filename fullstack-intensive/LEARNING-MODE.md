# Learning Mode (locked)

**You:** read, observe tools, ask questions, request quizzes at milestones.  
**Mentor (AI):** build, structure, explain, review understanding when asked.

**One product:** all milestones grow **BizFlow** (`projects/bizflow`). No new portfolio apps. Foundation sandboxes stay under `projects/_foundation/`.

## Every milestone delivers

1. Working software  
2. Clear folder architecture  
3. Inline comments on *why*, not only *what*  
4. A `docs/LEARN-MILESTONE-*.md` study brief  
5. Glossary updates  
6. Security / upgrade / process notes  

## Dimensions we always cover

| Dimension | Question we answer in the build |
|-----------|----------------------------------|
| Structure | Where does this file live and why? |
| Function | What behavior does the user get? |
| Scope | What is deliberately out? |
| Security / privacy | What must never leak or be trusted blindly? |
| Upgrade path | How do we change this later without a rewrite? |
| Cross-platform | Browser vs Node vs later mobile/API? |
| Time / shortcuts | **Good shortcuts only:** smallest *solid* design (clear boundaries, safe defaults, upgrade path). Never “fast” if it means weak validation, XSS, secrets in git, or dead-end structure. |
| Process | How would a team review/ship this? |
