# Full-Stack Engineering Intensive

Apprenticeship workspace: curriculum, foundation sandboxes, and the **BizFlow** portfolio product.

## Portfolio product

**[BizFlow](fullstack-intensive/projects/bizflow/)** — one app grown milestone by milestone.

```bash
cd fullstack-intensive/projects/bizflow
npm install
npm run dev
```

Roadmap: [fullstack-intensive/PRODUCT.md](fullstack-intensive/PRODUCT.md)

GitHub Actions builds BizFlow and runs the foundation expense-tracker self-check on every push to `main`.
